## 实现范围

- 等待、思考、工具、回答阶段与耗时反馈；真实思考内容可展开，展开时暂停底部跟随。
- 停止保留部分输出；失败重试、后台中断提示；继续追问、编辑问题和重新生成。
- Markdown 列表、标题、引用、代码与表格；整条消息复制、代码复制、代码横向滚动。
- SQLite 保存会话、草稿、停止/中断状态；恢复历史；防止空初始化快照覆盖已有记录。
- 流式 Markdown 使用 `useDeferredValue`，原始 SDK 快照仍立即更新与持久化；稳定 React key 避免每次 token 更新重建原生节点。
